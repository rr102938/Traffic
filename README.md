# Traffic Sign Recognition (CS50 AI)

## What it does
* This is a Python program that utilizes a Convolutional Neural Network (CNN) built with TensorFlow and OpenCV to classify and recognize different traffic signs from the German Traffic Sign Recognition Benchmark (GTSRB) dataset.
* It loads and preprocesses image data, trains a deep learning model, and evaluates its classification accuracy.

## Technologies Used
* Python
* TensorFlow / Keras (CNN Architecture)
* OpenCV (Open Source Computer Vision Library)
* scikit-learn (Data splitting)
* Git / GitHub
